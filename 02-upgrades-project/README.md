# Upgrade With Confidence — Project Record

This folder demonstrates the reusable UX Orchestrator on one synthetic device-upgrade problem: helping an eligible customer understand the complete financial effect before commitment.

| Phase | Primary question | Representative output |
|---|---|---|
| 01 Intake | What are we solving, for whom, and within which evidence boundary? | [`UX-BRIEF.md`](intake/UX-BRIEF.md) |
| 02 Discover | What can be supported by available evidence, expert review, and standards? | [`RESEARCH-FINDINGS.md`](discover/RESEARCH-FINDINGS.md) |
| 03 Define | Which risk and outcome should the design address? | [`PROBLEM-DEFINITION.md`](define/PROBLEM-DEFINITION.md) |
| 04 Design | How should the existing journey be enhanced without replacing its familiar patterns? | [`DESIGN-SPECIFICATION.md`](design/DESIGN-SPECIFICATION.md) |
| 05 Validate | Does the prototype cover the intended workflow, states, recovery, and accessibility behaviors? | [`VALIDATION-REPORT.md`](validate/VALIDATION-REPORT.md) |
| 06 Deliver | Is the final package coherent, traceable, and honest about limitations? | [`DELIVERY-SUMMARY.md`](deliver/DELIVERY-SUMMARY.md) |

Each phase contains artifacts, a gate result, and a handoff. Synthetic inputs and results are identified separately in [`../05-evidence/`](../05-evidence/).
