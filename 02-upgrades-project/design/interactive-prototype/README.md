# Upgrade With Confidence — Interactive Design Prototype

## Purpose

This buildless web prototype is the visual and interactive source for the Design phase of the synthetic **Upgrade With Confidence** project. It translates the approved design direction, information architecture, task flow, content, interaction states and accessibility requirements into a reviewable future-state experience.

It is not the chatbot and it does not represent a real carrier product, customer account, offer, policy or conversion result.

Current validated revision: `local-v2-v8`. This revision starts Upgrade Impact in an honest uncalculated state and includes executable missing-input and unknown-order recovery paths. The original `local-v1-v7` pilot findings remain preserved in the Validate records.

## Run locally

Open `index.html` directly in a browser, or serve this directory with any simple static server. No installation, build process, account or external service is required.

## Workspace pages

1. **Cover & inventory** — project framing and Figma-page inventory.
2. **Current design** — four live reference frames from the supplied Figma prototype.
3. **Visual audit** — recreated reference frames with numbered heuristic annotations.
4. **Flow & IA** — six-step task flow, edit/recovery branches and Upgrade Impact hierarchy.
5. **Foundations** — reference-informed colors, typography, spacing and explicit financial-status language.
6. **Components** — actions, selection cards, progress and Upgrade Impact patterns.
7. **Future design** — six connected customer screens with editable selections and calculated amounts.
8. **Responsive & states** — desktop/mobile behavior plus representative recovery states.
9. **Annotations** — accessibility behavior and the recommended Figma rebuild order.

## Interactive scenario

- Eligible line ending `2048`
- Nova X, `$899.99`, or `$25.00/month` for 36 months
- Estimated `$360.00` promotional trade-in value
- Conditional `$10.00/month` credits for 36 months
- Credits may take 1–2 synthetic billing cycles after inspection
- `$72.00` estimated device tax due today
- `$35.00` one-time fee on the next bill
- No plan change; synthetic plan remains `$65.00/month`
- `$0.00` standard shipping

An alternate device, full-price payment and no-trade-in branch are included so reviewers can see the Upgrade Impact update.

## Figma transfer

Use the workspace as a visual source, not as evidence of Figma completion. Rebuild in the separate file named **Upgrade With Confidence — Synthetic Future-State Prototype** in this order:

1. Create pages: Cover; Current design; Visual audit; Flow + IA; Foundations; Components; Desktop flow; Mobile + states; Annotations.
2. Create variables and styles from the Foundations page.
3. Create component variants before assembling screens.
4. Build and connect the six primary frames.
5. Add the representative responsive and recovery states.
6. Preserve the synthetic-data notice on the cover and prototype screens.
