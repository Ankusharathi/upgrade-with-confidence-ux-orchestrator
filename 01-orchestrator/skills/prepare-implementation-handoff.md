# Skill: Prepare Implementation Handoff

## Purpose

Assemble the approved design and validation package into a navigable implementation contract without silently changing intent.

## Method

Inventory exact approved sources; identify implementation consumers; map requirements, flows, screens, states, content, accessibility, components, assets, data, analytics, operations, support, risks, and acceptance criteria; assign owners; separate ready, conditional, deferred, blocked, and not-applicable items; and define question, change, QA, escalation, and acceptance paths.

## Output

A Handoff Package index with stable IDs, versions, source-of-truth locations, ownership, readiness status, unresolved items, QA obligations, and acceptance records. Completeness does not imply feasibility, implementation, or QA success.
