# Skill: Manage Implementation Decisions

## Purpose

Resolve implementation questions without losing design intent, authority, rationale, or downstream impact.

## Method

Log the question, source conflict, affected artifacts and criteria, options, evidence, recommendation, decision owner, due date, status, decision, rationale, and required updates. Escalate changes by impact: clarification stays in Deliver; behavior change returns to Design; outcome or evidence validity change returns to Validate; scope or problem change returns to Define; missing evidence returns to Discover.

## Output

An append-only question and decision log. Silence, meeting memory, chat, or agent inference is not an approved decision.
