# Skill: Verify Interaction and State Coverage

## Purpose

Verify implemented behavior across the approved task flow and complete state model, not only the happy path.

## Method

Exercise entry, navigation, role, permission, eligibility, loading, empty, unavailable, validation, error, interruption, timeout, retry, cancellation, recovery, confirmation, duplicate prevention, completion, and post-task behavior as applicable. For each check record setup, steps, expected behavior, observed behavior, evidence, result, environment, and issue ID.

## Output

A coverage result that explicitly lists passed, failed, blocked, deferred, not-applicable, and untested states.
