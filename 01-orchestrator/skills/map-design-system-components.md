# Skill: Map Design-System Components

## Purpose

Map approved UI elements to governed components, variants, tokens, assets, and ownership.

## Method

Record library and version, component and variant, properties, tokens, responsive rules, interaction states, content constraints, accessibility behavior, platform differences, availability, and implementation owner. Classify reuse, extension, new component, exception, or unresolved mapping. Record contribution and approval paths for extensions.

## Output

A component map with no false claim that a component, token, asset, or variant exists or is approved.
