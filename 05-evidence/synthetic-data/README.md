# Synthetic Data Register

The following project material is synthetic or simulated:

- Example customer, device, plan, payment, fee, and trade-in values in the prototype
- [`Synthetic funnel model`](../../02-upgrades-project/discover/SYNTHETIC-FUNNEL-MODEL.md)
- Illustrative research statements and scenario inputs
- Workflow-validation sessions and targeted retest records
- Any numerical outcome used to demonstrate how an artifact would be structured

These records are suitable for demonstrating process, traceability, calculations, states, and evaluation design. They must not be presented as Verizon research, operational analytics, or measured customer behavior.
